# hedronfire: issues and test reports

This repository holds bug reports and test results for [hedronfire](https://www.hedronfire.com/), a Gentoo-based
meta distro. It has no code. The source lives at
[git.hedronfire.com/hedronfire.git](https://git.hedronfire.com/hedronfire.git/tree/).

- **Tried the test ISO?** [Open a test report](https://github.com/hedronfire/os-issues/issues/new?template=test-report.yml),
  whether the install worked or not. Reports from real hardware help most, especially ZFS and encrypted installs.
- **Questions:** ask in [#hedronfire on Libera.Chat](https://web.libera.chat/#hedronfire).

The test ISO, its checksums and its signature are on the [download section](https://www.hedronfire.com/#install).
The installer erases the disk you choose.
